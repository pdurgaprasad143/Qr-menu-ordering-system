The QR based restaurant ordering system is a modern ,contactless dining solution designed to enhance the restaurant experience for both customers and staff.This system allows customers to scan a QR-code at  their table using their smartphones,access a digital menu,and place orders directly
from their mobile browser-eliminating the need for physical menus and manual order taking, The system features a responsive design, ensuring seamless functionality on all devices. Customers can browse categorized menu items,add selections to their cart ,and submit their orders. The admin dashboard, 
designed for restaurent staff, enables real-time order managment,allowing them to view ,update ,and track order statuses efficiently. This solution reduce human erros,speeds up services ,and enhances operational efficiency in restaurants.Future enhancement may include real-time order tracking,
online payments,and AI-based menu recommendations. By levaraging React.js,this project delivers a user-friendly and scalable approach to streamline restaurant operations and improve customers satisfaction.
